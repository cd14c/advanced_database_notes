## What I understood
- Like aggregate functions, but you use OVER() to make it an analytic function
- You can use many other functions with OVER(), such as:
    - PARTITION BY()
    - ORDER BY()
    - range
- Creates a new column to be added to the table
- OVER() with no argument takes all the table
- With PARTITION BY you can slice the data depending on a specific column value
- You can calculate the percent of total with amount * 100.0 / SUM(amount) OVER() AS pct_of_total, for example
- If you use ORDER BY() with OVER(), the function becomes cumulative (in other words, makes the count up to the column instead of counting all)
- You can combine PARTITION BY() and ORDER BY() to, for example, calculate the cumulative sum of sales by date by person
- You can make a sliding window by stating what rows are to be counted
