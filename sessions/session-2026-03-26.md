## What I understood
- Triggers are executed automatically when a condition is met
- You declare them with CREATE (OR REPLACE para reemplazar si ya existe, normalmente se escriben juntos)
- You use the words BEFORE or AFTER to declare whether it executes before or after the trigger
- You need either an INSERT, UPDATE, or DELETE as the trigger, but more than one can be used at the same time
- The :NEW variable serves to indicate the new data in a record
- The :OLD variable serves to indicate the old data in a record
- Can be used to keep logs, backups or ensure data is within the accepted window
- You can use CONSTRAINT to check if a variable is in the accepted variables
