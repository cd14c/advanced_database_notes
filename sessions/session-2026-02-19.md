## What I understood
- Each table has a key
- How to link two tables
- Best practices to not double the registry of the same object/person and make another table instead
- How to join two tables with SELECT and JOIN, using a shared id on both tables
- INNER JOIN is used to get only the records shared by both tables joined
- LEFT JOIN gets all records on the left table
- RIGHT JOIN gets all records on the right table
- If a JOIN has no other word, the default used is INNER JOIN
- CROSS JOIN is used to combine each individual record with each individual record of another table
- A JOIN can be used on a single table, joining two instances of itself to make reference to other records (for example, in a table employees with a column for managers that make reference to other rows by id, you can make a JOIN with an alias to show the name of the managers)
- If two columns on two tables to be joined are named the same, you have to make references to them in the statement like this: "employees.name", "managers.name"
